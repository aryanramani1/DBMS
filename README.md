# Online Food Delivery System - DBMS Project

This repository features a DBMS course project on an online food delivery system. It includes a website with essential pages (homepage, menu, payment, confirmation), an SQL database for menu items and user queries, and the project presentation.

## Included Components
- **Presentation**: `Food_Delivery_Management_System_Detailed_Presentation  -  Repaired (3).pptx`
- **Source Code**: `DBMS/` directory (HTML, CSS, JS frontend pages)
- **Database Schema**: `DBMS/res_database.sql`

## Features:
1. **Homepage (`DBMS/Homepage.html`)**: Landing page introducing the food delivery service with restaurant area selection.
2. **Menu Page (`DBMS/menu.html`)**: Displays food categories and items with cart functionality.
3. **Payment Page (`DBMS/payment.html`)**: User details collection and payment method selection.
4. **Confirmation Page (`DBMS/confirm_page.html`)**: Order confirmation and details.

## SQL Database:
Contains tables for menu items, user details, orders, and transaction records (`DBMS/res_database.sql`).
